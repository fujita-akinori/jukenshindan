数弱が数強になるための武器：論理

2026.07.08 公開 PRこの記事にはアフィリエイト広告が含まれています 執筆：受験診断ドットコム運営メンバー（現役京大生）

数学が苦手な受験生の多くは計算ができないわけではありません。つまずいているのは問題を解き進めるときの論理の運び方です。ここでいう論理とは「AならばB」「必要条件と十分条件」「同値」「対偶」といった考え方の骨組みのことで、日本語でいえば文法にあたります。

楽天で見る

筆者も伸び悩んでいた

筆者は4STEPと青チャートに取り組んでいましたが、数学は河合塾の模試で偏差値60前後をさまよっていました。京大理系志望の中では最下位付近です。それでも本番では合格者平均を大きく超える点数を取ることができました。

理由ははっきりしていて、高2のときに論理の大切さに気付けたからです。問題集の解法をどれだけ覚えても、自分が何をしていてなぜその問題が解けるのかを説明できなければ、初見の問題では手が止まります。論理はその「なぜ」を目に見える形にしてくれる道具です。

論理は上級者向けではない

論理を意識した勉強法は上級者向けだと言われることがあります。筆者の考えは逆で、論理こそ数学が苦手な人がやるべきものです。

日本語の文法で考えてみてください。文法を何も知らないまま日本語の文章を大量に浴びせられたとき、頭のいい人はその中からAIのようにパターンを分析して、なんとなく文法を身につけ、自分で文章を作れるようになります。そうでない人は同じ量の文章を浴びてもそれができません。その人たちは文法を学ぶことで話せるようになります。

数学も同じです。数強と呼ばれる人たちは、論理を学ばなくても解法を覚えながら「なぜだろう」と疑問を持って解くうちに、自然と論理を身につけています。数弱はそこから同じように吸収することができません。だから数弱は論理を意識的に学ぶことで、数強が無意識に得ている学習効果を手に入れられます。論理は数強と数弱の差を縮めるための道具です。

論理を無視するとどこで失点するか

論理が抜けている人の失点にはよく似た形があります。次の4つに心当たりがあれば、伸び悩みの原因は演習量ではなく論理です。

1. 同値でない変形をして答えが増える

方程式 √(x+2) = x を解くとき、両辺を2乗すると x+2 = x² となり x = 2 と x = −1 が出てきます。ところが x = −1 を元の式に入れると左辺は1で右辺は−1です。

2乗するという操作は「元の式ならば2乗した式」という一方通行の変形で、逆は成り立ちません。右辺が0以上という条件を一緒に持っておけば x = 2 だけが残ります。式変形のたびに今の変形は同値か一方通行かを意識しているかどうかで、こうした失点はなくなります。

2. 必要条件だけで答えを出してしまう

「f(x) = x³ + ax² + 3x + 1 が x = −1 で極値をとるような a を求めよ」という問題を考えます。f′(−1) = 0 から 6 − 2a = 0 となり a = 3 です。

しかし a = 3 のとき f′(x) = 3x² + 6x + 3 = 3(x+1)² となり、f′(x) は x = −1 の前後で符号を変えません。つまり x = −1 で極値をとることはなく、答えは「そのような a は存在しない」です。f′(−1) = 0 は極値をとるための必要条件にすぎず、十分性を確かめて初めて答えになります。

3. 軌跡で除外点を落とす

2直線 y = mx と x + my − 2m = 0 の交点が、m がすべての実数を動くときにどんな図形を描くかを考えます。1本目の式から m = y/x として2本目に代入すると x² + y² − 2y = 0 となり、円 x² + (y−1)² = 1 が出てきます。

ここで答えを円としてしまうと大きく減点されます。m = y/x と置いた時点で x ≠ 0 を勝手に仮定しているからです。x = 0 のときを調べると1本目の式から y = 0 となり、原点は m = 0 のときに実際に通ります。一方で円上の点 (0, 2) はどんな m でも通らないので、答えは「円 x² + (y−1)² = 1 ただし点 (0, 2) を除く」です。

軌跡の問題は「この点を通るような m が存在するか」を調べる問題です。そう読めていれば、文字で割った瞬間に割れない場合を確認しに行けます。除外点を忘れる人の多くは、除外点の覚え方ではなく問題の論理構造を読み飛ばしています。

4. 正面から解こうとして時間が足りなくなる

「n² が偶数ならば n は偶数であることを示せ」は、そのまま示そうとすると手が止まります。対偶の「n が奇数ならば n² は奇数」に言い換えれば、n = 2k + 1 とおいて2乗するだけで終わります。命題とその対偶は真偽が一致するという一点を知っているだけで、難関大の証明問題でも打開できる場面が増えます。

論理を身につける順番

論理は特別な才能ではなく、順番に積み上げれば誰でも身につきます。

  • 教科書の「集合と論理」を学び直す：必要条件と十分条件、命題の否定、対偶を自分の言葉で説明できる状態にします。多くの受験生が流し読みで済ませる単元ですが、ほかの全分野を支える土台です。
  • 講義本で使い方を見る：「志田晶の 集合・論理、整数が面白いほどわかる本」のような講義形式の1冊で、論理が実際の問題でどう使われるかを確認します。
  • 答案に「なぜ」を書く：普段の演習で式変形のたびに同値か一方通行かを書き添えます。解答を写すのではなく一行ごとに理由を言えるかどうかが、論理力の伸びを左右します。記述の書き方そのものを学ぶなら「総合的研究 記述式答案の書き方」が役に立ちます。
  • 論理そのものを掘り下げる：東大や京大を目指すなら「総合的研究 論理学で学ぶ数学」で論理を体系的に学ぶ段階に進みます。基礎が固まってから取り組む1冊です。
論理は解法の暗記と対立するものではありません。覚えた解法がなぜ使えるのかを論理で説明できるようになると、同じ解法を初見の問題に持ち込めるようになります。解法暗記と理解の関係は「解法暗記VS理解、受験数学はどっちが正解か」でも整理しています。

結論

偏差値60前後で止まっていた筆者が本番で点を取れたのは、問題集の量を増やしたからではなく、自分が何をしているのかを論理で確かめながら解くようになったからです。数強が無意識にやっていることを、数弱は論理を学ぶことで意識的にできるようになります。パターン暗記で頭打ちを感じているなら、一度「論理」に立ち返ってみる価値があります。
